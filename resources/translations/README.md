# Qt 6.8.3 简体中文翻译资源

`qtbase_zh_CN.ts` 是 Qt 社区提供的原始翻译，未作修改。来源为官方
[qt/qttranslations v6.8.3](https://github.com/qt/qttranslations/tree/v6.8.3)，
对应提交 `abe01d7de31d311db8bc485d4e7e8d0c30493425`，
[原始文件](https://github.com/qt/qttranslations/blob/v6.8.3/translations/qtbase_zh_CN.ts)。
下载通过官方 GitHub API 取得原始字节，并核对该提交树的 Git blob 摘要。

`qtbase_zh_CN.qm` 使用项目固定版本 Qt 6.8.3 的 `lrelease` 编译，
格式与平台无关。生成 1,696 条完成的翻译，忽略 90 条上游尚未翻译的文本；
没有自行补写缺失翻译。上游不保证翻译完整性或准确性，原始说明保存在
`UPSTREAM_README.txt`。

```sh
lrelease qtbase_zh_CN.ts -qm qtbase_zh_CN.qm
```

完整文本同时附在本目录，来自官方 Qt Base v6.8.3 的 LICENSES 目录。

重新编译和替换翻译。`PROVENANCE.json` 记录官方来源、Git blob 和文件摘要。
