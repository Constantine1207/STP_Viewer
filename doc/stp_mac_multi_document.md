# Mac 多文件标签页

2026-10-02。仅调整 Mac 交互入口，Windows 便携包与交互入口保留原样。

打开按钮支持多选，拖放和命令行支持多个 STEP。每个文件有独立标签页，可以拖动排序；标签显示文件名，悬停显示完整路径。同名不同目录的文件以目录区分；同一规范化路径只激活已有标签，不重复导入。收到 macOS 文件打开事件时也走同一入口。

每页保留三维相机、显示/剖切/爆炸/透明度、标注显隐、装配树勾选和搜索、人工材料与密度及 BOM 页面。标签切换提交正在编辑的单元格。菜单及导出只作用于当前标签，后台完成不会切走当前页面。

标签 × 或文件菜单“关闭当前”（⌘W）关闭单个；“关闭全部”返回欢迎页面，可继续打开。关闭直接丢弃会话数据，不弹保存提示；再次打开已关闭文件读取原始属性。关闭后台页不改变活动页，关闭活动页选择相邻页。

应用级 CadJobQueue 使用一个持久工作线程，以 FIFO 顺序执行导入、几何/PMI、网格更新和导出。各任务绑定会话 ID；UI/AIS 显示仍在主线程。关闭先移除标签，再取消排队任务、请求运行任务安全取消，清理后销毁页面。主线程不等待 CAD 操作，不强行终止线程。应用退出等清理完成后再关闭；关闭全部文档时队列可继续服务新打开的文件。

首次未显示页等待 OpenGL 初始化后建立 AIS，已显示页切换只重绘。资源在所属 OpenGL 上下文内释放。取消初始显示或导入失败时，页面提供“重试读取”；单文件 `--smoke-test` 保持原接口和退出方式。

原生回归使用 cube、彩色嵌套装配、基础 PMI 和 2,000 重复实例样例。验证文件与人工属性独立、菜单转发、九次切换的真实模型像素、排队及运行中关闭、取消后重试和异步退出。分别从两个活动文件通过主菜单导出 Excel 与拆分 STEP，再读取校验人工材料、密度、质量、勾选数量、来源路径及原始几何；排队导出期间关闭时不生成文件或弹窗。另运行原有 CAD/PMI、颜色/平移/爆炸/剖切/精度、布局和实际导出回归。机器为现有 Apple Silicon Mac；这些检查不增加 macOS 12、另一台干净 Mac 或真实 200 MB 装配体的验收范围。

关闭任务的专项覆盖范围：真实导入、网格更新及 Excel 导出覆盖排队中关闭；运行中关闭与退出使用会话绑定的协作取消测试作业；真实 2,000 实例的 AIS 场景构建覆盖取消和原页重试。不能据此声称已在任意大型 STEP 解析或导出的每个运行阶段逐项完成关闭验证。
