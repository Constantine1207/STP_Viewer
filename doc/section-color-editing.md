# 自定义剖切、封盖随色与零件着色

新增功能基于此前已验证的 Windows 版本开发。本文件说明功能范围；实际构建和验证结果以同一下载包内的 `windows-build-report.json` 和 `validation/windows/` 为准。

## 操作入口

- 原“剖切”页：选择 YZ（法向 X）、ZX（法向 Y）、XY（法向 Z），或点击“拾取零件平面”后点击模型上的平面。Esc 或“取消拾取”退出拾取。拾取期间暂时关闭剖切；进入拾取会复位显示用爆炸/抓手位移，保留已应用的位置编辑。
- 设置旋转轴、角度与旋转中心；再沿旋转后法向设置 mm 偏移。数值相对基准面计算，滑块为快速调节，不限制精确数值输入。标准基准面经过导入装配包围盒中心；零件面基准固定于拾取时的世界坐标，不跟随后续零件移动。
- 勾选“显示剖切平面轮廓”显示参考边框与法向；“反向”切换保留侧；“复位并关闭剖切”恢复初始控制状态。当前仅支持精确平面，曲面会提示重新选择。
- “封盖随零件颜色”默认开启，每个零件采用自身当前主色。关闭时使用统一橙色。多面颜色零件采用零件主色；缺少主色时使用中性灰。封盖针对有效闭合实体，开放曲面不能保证得到封闭截面。
- 从装配树或模型选中零件，点击顶部“零件颜色…”；也可右键“零件颜色…”。支持多选统一着色、恢复选中零件原色、“撤销着色”和“重做着色”（视图菜单及零件右键菜单）。同源零件实例可分别着色。
- 位置与着色各保留自己的撤销历史；位置编辑页处理位置，视图菜单处理着色。颜色修改参与文件标签星号、关闭保存提示和另存后的已保存状态。

## STEP 保存范围

“文件 → 另存 STEP…”保存完整精确几何、已应用的位置和零件新颜色，使用原有 AP242 / mm 写出入口。剖切、封盖、平面轮廓、背景、临时透明、隐藏、爆炸及抓手仅为显示状态，不裁剪或添加 STEP 实体。仍保留原版本关于 PMI、人工补填材料和原始 BOM／拆分导出的限制。

改色覆盖整件显示及该实例导出的面颜色；恢复原色从导入数据还原。同源实例通过独立的颜色编辑与必要的导出定义隔离；原始 XDE 不作修改。另存后重新打开文件，颜色成为新文件的原始颜色。

## 自动验证

- `stp_section_color_tests`：平面旋转/自定义中心/偏移/反向、精确平面识别、重复子装配实例独立改色、所有实例改色时无额外自由零件、位置与全量几何、原面色/材料/密度、STEP 回读、中文路径、取消保护和源数据不变。
- `stp_section_color_integration_tests`：实际鼠标选面与 Esc、控制器联动、颜色对话框和多选撤销/重做/恢复、实际封盖像素及贯通孔、透明度/重建网格、文件菜单另存并回读、标签页隔离和未保存关闭提示。
- Windows 云端使用 `-SkipGuiTests -RunFeatureGuiTests`：执行以上专项 GUI 测试及原有位置/背景集成回归；完整历史交互回归仍单独标记未执行。核心测试和便携包图形/测量/单 EXE 自检继续执行。

物理显卡、实际工程装配和目标 CAD 回读需在用户 Windows 电脑确认。此前记录的 Workspace 截图采样断言问题没有通过降低阈值隐藏。
