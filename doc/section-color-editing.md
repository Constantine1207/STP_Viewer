# 自定义剖切、封盖随色与零件着色

新增功能基于此前已验证的 Windows 版本开发。本文件说明功能范围；实际构建和验证结果以同一下载包内的 `windows-build-report.json` 和 `validation/windows/` 为准。

## 操作入口

- 底部“剖切 → 打开剖切设置…”或“视图 → 剖切设置…”进入右侧“剖切设置”页。选择 YZ（法向 X）、ZX（法向 Y）、XY（法向 Z），或点击“拾取零件平面”后点击模型上的平面。Esc 或“取消拾取”退出拾取。拾取期间暂时关闭剖切；进入拾取会复位显示用爆炸/抓手位移，保留已应用的位置编辑。
- 设置旋转轴、角度与旋转中心；再沿旋转后法向设置 mm 偏移。数值相对基准面计算，滑块为快速调节，不限制精确数值输入。标准基准面经过导入装配包围盒中心；零件面基准固定于拾取时的世界坐标，不跟随后续零件移动。
- 勾选“显示剖切平面轮廓”显示参考边框与法向；“反向”切换保留侧；“复位并关闭剖切”恢复初始控制状态。当前仅支持精确平面，曲面会提示重新选择。
- “封盖随零件颜色”默认开启，每个零件采用自身当前主色。关闭时使用统一橙色。多面颜色零件采用零件主色；缺少主色时使用中性灰。封盖针对有效闭合实体，开放曲面不能保证得到封闭截面。
- 从装配树或模型选中零件，点击顶部“零件颜色…”；也可右键“零件颜色…”。支持多选统一着色、恢复选中零件原色、“撤销着色”和“重做着色”（视图菜单及零件右键菜单）。同源零件实例可分别着色。
- 位置与着色各保留自己的撤销历史；位置编辑页处理位置，视图菜单处理着色。颜色修改参与文件标签星号、关闭保存提示和另存后的已保存状态。

## STEP 保存范围

“文件 → 另存 STEP…”保存完整精确几何、已应用的位置和零件新颜色，使用原有 AP242 / mm 写出入口。剖切、封盖、平面轮廓、背景、临时透明、隐藏、爆炸及抓手仅为显示状态，不裁剪或添加 STEP 实体。仍保留原版本关于 PMI、人工补填材料和原始 BOM／拆分导出的限制。

改色覆盖整件显示及该实例导出的面颜色；恢复原色从导入数据还原。同源实例通过独立的颜色编辑与必要的导出定义隔离；原始 XDE 不作修改。另存后重新打开文件，颜色成为新文件的原始颜色。

## 自动验证

- `stp_section_color_tests`：平面旋转/自定义中心/偏移/反向、精确平面识别、重复子装配实例独立改色、所有实例改色时无额外自由零件、位置与全量几何、原面色/材料/密度、STEP 回读、中文路径、取消保护和源数据不变。
- `stp_section_color_integration_tests`：实际鼠标选面与 Esc、控制器联动、颜色对话框和多选撤销/重做/恢复、实际封盖像素及贯通孔、透明度/重建网格、文件菜单另存并回读、标签页隔离和未保存关闭提示。
- Windows 云端默认执行 7 项 CTest 和全部 7 组 GUI 回归：位置/背景、剖切/颜色、Viewer、测量、Workspace、Appearance、Layout。每组单独写入结果；发生失败仍收集其余 GUI 结果，但不继续生成通过验收的交付包。`-SkipGuiTests -RunFeatureGuiTests` 仍可供局部开发时只运行两组专项 GUI。核心测试和便携包图形/测量/单 EXE 自检继续执行。

## 历史未通过项的修正

2026-11-02 在未修改应用代码的基线上重新开启 Windows 完整 GUI 回归，复现了 Workspace 问题（[运行记录](https://github.com/Constantine1207/STP_Viewer/actions/runs/41435628110)）：

- 原截图判据只采样中间 60% 的画面；1000×700 装配截图的中央前景样本仅 79 个，但图像中的边缘零件正常显示。改为在当前实例投影区域逐像素比较，与同一视角、背景和坐标轴的空模型截图作差，要求超过 100 个真实差异像素且投影覆盖率至少 10%，避免固定间隔采样漏计小零件。另加真实的“仅有坐标轴”反例，验证空画面不会通过。
- 剖切设置移至右侧后，底部控件为 10 个，旧测试仍要求至少 11 个。新检查按控件名称核对功能是否齐全，并实际打开右侧剖切页，逐项滚动检查控件可达性；不再通过控件总数推断完整性。
- 云端初始桌面约 1024×768，无法可靠执行 1440×831 的尺寸恢复断言。工作流中的独立辅助程序通过 Win32 显示 API 设置并核验 1920×1080，仅作用于临时 GitHub Actions 会话，不随便携包发布，也不更改用户电脑分辨率。
- Layout 的鼠标/键盘剖切测试改为先从真实入口打开右侧设置页，操作后恢复原属性页。测量页和测量记录页改为按实际控件定位；原测试固定要求 4 个属性标签，新增剖切和位置编辑页后该数量假设已失效。900×640、1000×700 和 1440×820 的测量操作区及记录区仍分别检查可见性。抓手测试临时关闭剖切后，完整恢复原基准、角度和偏移，再逐项核对页面切换是否保留相机、选择、透明度与剖切位置，避免测试准备步骤改变后续用例的初始状态。

本轮实际通过状态、源码提交和截图以下载包内 `windows-build-report.json`、`validation/windows/workspace/workspace-report.json` 及其他分组报告为准。上述变更保持应用的 STEP 保存范围不变。

物理显卡、实际工程装配和目标 CAD 回读仍需在用户 Windows 电脑确认。Linux 的旧结果属于历史环境记录，本轮 Windows 检查不能替代 Linux/macOS 或物理显卡实测。PMI 重新导出仍为未实现范围。
