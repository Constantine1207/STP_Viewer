# Windows 测量与单文件便携版

Windows 版同步 Mac 的测量、测量记录和抓手功能。测量操作见 [工程测量说明](stp_mac_measurement.md)，抓手操作见 [抓手说明](stp_mac_part_grab.md)；这两份说明中的平台名称不再限制功能入口。

## 同步范围

- 点坐标、长度、半径、直径、面积、体积、质量、质量中心及体积中心；圆心、圆弧／圆柱／圆锥轴线拾取。
- 点／线／面／体之间最小距离与角度；A/B 独立无限拓展，仅解析直线边及平面面支持。轴线天然无限。
- 操作页及记录页分开；默认三位小数，保留多条历史、单条隐藏／删除／复制、清除所有测量及计算取消。
- 每个文件独立记录、原始／显示位置、爆炸及抓手位移快照，旧位置标注失效规则保持一致。
- 轴线和拓展测量的三维标注仅显示测量类型、数值及单位，不显示 M 编号或无穷符号；记录页保留编号。
- Windows 使用 Ctrl 键快捷操作；900×640 为窗口最小逻辑尺寸。Mac 的 Cocoa 无障碍兼容补丁不进入 Windows。

## 单个 EXE 的实际行为

`STPViewer-1.0.0-windows-x64-portable.exe` 是无需安装的自解压便携启动包。可单独移动及复制 EXE，不需要旁边放 DLL 或手动解压。首次启动会将内嵌、SHA-256 校验的 ZIP 解压到 `%LOCALAPPDATA%\STPViewer\Portable\<包哈希>`；后续验证并复用缓存，不写入应用程序安装目录，不需要管理员权限，不联网。

运行仍需要该用户缓存中的 Qt、OCCT、Visual C++ 运行库、插件和资源；这不是所有代码都静态链接且不落地依赖的 EXE。单文件启动器使用 Windows .NET Framework 4.x，构建为 x64。最终支持范围以实际 Windows 验证报告为准。

缓存损坏会重新解压，旧缓存保留为 `.previous-<编号>`，避免直接删除未知文件。不同版本按哈希隔离，多个同时启动的同版本通过互斥锁协调。可在关闭全部程序后删除此应用专用缓存，下次启动重新生成；缓存不保存 STEP 文件和测量历史，测量仍仅保留于文件会话。

单 EXE 和原有 ZIP 便携包同时提供。ZIP 用户须完整解压并保留目录内的 DLL／资源。发行包目前未做 Microsoft Authenticode 签名，不关闭或绕过系统安全检查。
