# Mac 抓手摆放

2026-10-04 图标更新。Mac 的装配爆炸区提供手掌图标切换按钮，位于范围下拉框旁；“视图 → 抓手”提供相同入口。关闭时显示展开手掌，开启时显示蓝底抓握手掌，右侧提示同步显示状态。两种手形均为侧面轮廓，手腕从右上伸入、朝左下抓取，四指并拢，拇指单独配合抓握。图形使用可缩放矢量资源，按钮仍保留“抓手”辅助功能名称和操作提示。读取模型、生成三维显示和更新显示精度期间暂不可操作；模型显示完成后可用。

## 操作

- 抓手关闭时，左键拖动旋转视图。
- 抓手开启时，左键单击选中一个零件实例，按住左键拖动可沿当前屏幕平面摆放；零件朝向保持不变，松开后位置保留。再次拖动从当前位置继续。
- 每次只移动鼠标命中的实例，重复定义的其他实例保持原位。空白处拖动不旋转相机，也不拖动之前选中的零件。
- 关闭抓手恢复左键旋转，已摆放位置继续保留。右键菜单、右键或中键平移、滚轮缩放、双击或 F 适配窗口继续可用。
- 装配爆炸区“复位”无论爆炸滑条是否已经为零，都恢复当前文件的全部零件到导入位置并将爆炸归零；相机、选择、抓手开关和外观状态保留。

爆炸位移与手动摆放叠加，切换爆炸范围或调整滑条不会丢失已完成的摆放。剖切继续使用原始装配包围盒，不随抓手移动平面。位置复位不会重置剖切设置。外观“还原一步”和“全部复原”仍仅恢复临时透明与隐藏，恢复摆放需使用装配爆炸区“复位”。

## 文件与数据

抓手模式和摆放位置按文件标签独立保留。切换标签、进入 BOM 页、更新显示精度或关闭文件时结束当前拖动，不留下继续移动的手势；已完成的位置在标签切换和网格重建后保留。同一路径再次打开只激活原标签，关闭后重新打开才恢复初始位置与关闭的抓手模式。

摆放只作用于三维显示，不修改源 STEP、XDE 装配位置、精确几何、工程属性和 BOM。Excel 实例位置及拆分 STEP 继续使用原始数据。可确认唯一归属的 PMI 跟随零件；无法安全归属的装配标注在摆放后暂时隐藏，位置复位后恢复。

新增界面和鼠标行为由 `Q_OS_MACOS` 条件启用，Windows 本次不增加抓手入口。

## 本次验证

2026-10-03 在本机完成 Release / arm64 构建。数据服务 CTest 3/3 通过；原生三维、界面布局、多文件工作区及临时外观回归均通过。三维专项覆盖正交/透视、不同缩放、Retina 坐标、重复嵌套实例、连续与单段移动等价、释放最终落点、光标、相机冻结、失焦/隐藏/漏释放以及精度重建。界面回归实际点击抓手开关并验证关闭后左键旋转恢复，爆炸滑条为零时点击复位仍还原全部实例；四种窗口尺寸的控制区可达。

多文件回归在摆放后通过真实界面导出 Excel 与拆分 STEP，逐实例核对 Excel 原始位置与旋转矩阵，回读 STEP 几何与属性，确认摆放不进入导出。快捷键回归原先依赖固定 30 ms 激活等待，本次改为等待窗口实际激活并发送 QAction 的平台快捷键；初次失败和通过报告均保留。

原生证据位于 `dist/validation/mac-part-grab/`，包括三维抓取/复位截图、`layout/layout-report.json`、`workspace/workspace-report.json`、`appearance/appearance-report.json` 与 `ctest.log`。便携 ZIP 和签名/搬移报告位于 `dist/mac-part-grab/`；最终搬移结果以 `macos-bundle-validation.json` 为准。

## 验证入口

原生交互回归使用真实 Qt 鼠标事件、OCCT 相机与 AIS 变换，不以按钮文本或截图单独证明拖动正确。需要 Mac 图形桌面和可用 OpenGL：

```sh
.tools/venv/bin/cmake --build build --target STPViewer stp_viewer_tests stp_mac_layout_tests stp_workspace_tests stp_appearance_tests --parallel 6
build/stp_viewer_tests samples/colored-assembly.step
build/stp_mac_layout_tests 输出目录 samples/colored-assembly.step
build/stp_workspace_tests 输出目录 源码根目录
build/stp_appearance_tests 输出目录 源码根目录
bash scripts/package-macos.sh build/STPViewer.app --output dist/mac-part-grab
```

开发目录运行测试时需确保 Qt 平台插件可被找到；便携包有独立的插件与运行资源。数据服务继续使用 CTest；GUI 回归需单独执行。便携打包执行签名和搬移自检，抓手行为由原生交互回归另行验证。实际通过结果以本次交付测试报告为准；当前构建主机的验证不能代替 macOS 12 实机、另一台干净 Mac 或任意大型装配体的验收。
