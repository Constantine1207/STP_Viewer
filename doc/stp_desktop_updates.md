# 2026-10-03 桌面功能同步

本文为 2026-10-03 的历史同步记录；当前正式版本与 Windows 10 x64／Windows 11 x64 作者实测范围见 [验证说明](../VALIDATION.md)。

Mac 与 Windows 共用 `DocumentWorkspace`、`MainWindow`、`ViewerWidget`、`CadJobQueue` 及 CAD 服务。此前的 Mac 功能分支已合并到共用实现，避免后续平台功能漂移。

| 功能 | 两平台行为 |
|---|---|
| 界面 | 三维默认页、BOM 与导入诊断独立页、右侧操作提示、窄窗口滚动控件 |
| 文件会话 | 多选打开、拖放、命令行多文件、重复路径复用、独立状态、关闭当前/全部、欢迎页 |
| 人工属性 | 两处编辑缺失材料/密度、来源标识、密度参与质量计算、切换与导出前提交 |
| 勾选范围 | 仅勾选的叶级实例计入 BOM、Excel 与 STEP 导出，临时隐藏不改变范围 |
| 右键与还原 | 单击拾取一个实例、70% 透明、临时隐藏、右拖平移、100 步历史与全部复原 |
| 后台生命周期 | 串行 CAD 队列，取消排队/运行任务，关闭页异步安全清理，其他已加载文件可操作 |
| 拆分反馈 | 完成框、状态栏及诊断保留输出路径，按钮打开实际批次目录 |
| 品牌 | 持续显示作者签名，AEME 应用图标 |

Windows 用窗口内菜单及 Ctrl+W；Mac 用原生菜单及 ⌘W。Windows 的文件夹按钮打开资源管理器。Windows ICO 含 16、24、32、48、64、128、256 像素表示，EXE 内嵌图标，窗口与任务栏加载同源图像。Mac 保留 ICNS 及 Cocoa 无障碍兼容处理。Apple OpenGL 4.1 和 Finder 隐藏属性修复仅用于 Mac。

`build-windows.ps1` 构建并运行核心、PMI、队列、三维交互、多标签、外观与布局回归，再审计便携包依赖并运行四个解压搬移自检。界面测试需要交互桌面和 OpenGL。`-SkipGuiTests` 会明确记录未运行项，不能作为界面验收。

本次最终证据见发行目录 `WINDOWS_SYNC.md` 和 `validation/windows-sync/`。Windows 11 ARM64 虚拟机通过 x64 仿真验证，并不等于 Windows x64 实机、Windows 10 1809 或全新无开发依赖系统已验收。目标 200 MB/2,000 实例的完整性能验收和任意 STEP 的 PMI 全保真不在此同步结论内。

实际回归已在可用 Mac 与 Windows 虚拟机通过。Windows 的路径大小写别名也验证为复用原标签。自动导出测试使用独立批次路径、一次提交的对话框接受和受保护的窗口指针，避免重复运行因旧工作簿触发覆盖确认及重复定时提交；完整日志保留失败尝试与修复后的结果，不以旧结果冒充新运行。
