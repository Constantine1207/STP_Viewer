# Mac 零件外观操作与还原

右键单击拾取一个叶级零件实例、同步选中并显示非阻塞菜单；右键拖动继续平移。空白点击不改变原选择，菜单禁用零件操作。Mac 原生自动上下文菜单事件被消费，避免与释放时菜单重复。

零件的临时隐藏和 70% 透明覆盖按实例保存，同一定义的其他实例不受影响。临时隐藏不改变基础可见状态、树勾选或 BOM；最终显隐结合基础状态与临时隐藏。树中的图标及说明用于区分二者。零件自有标注随临时隐藏，跨零件标注仍遵循原有诊断及显隐规则。

现有整体/选中透明度属于同一外观状态。显式调整滑条清除作用范围内的右键透明覆盖，选择变化只重新计算显示，不清除覆盖。零透明表示移除临时覆盖并重新应用 XDE 源样式，保留原始面色与透明度。Mac 的选择及悬停高亮不覆盖透明表面。

每个文件页面保存最多 100 步外观历史；状态仅包含整体透明值、选中范围开关、实例覆盖及临时隐藏，不包含几何、AIS、基础勾选或相机。一次完整滑条拖动结算一条，其他显式变更按操作记录；没有变化不入栈。恢复阻断控件信号，保持当前逻辑选择，不录入新的历史。全部复原清除外观临时状态及历史，保留其他文件会话数据。

“显示全部”保持原有勾选逻辑，同时清除临时隐藏；仅后者作为可撤销外观操作。撤销不回滚树勾选和导出范围。新的文档读取清空历史，标签切换或重复打开原路径保留历史；网格替换按实例状态应用外观。忙碌及关闭期间禁用操作，并关闭页面所属弹出菜单。

仅编译启用 Mac 新交互，Windows 应用和便携包不更新。`stp_appearance_tests` 验证真实鼠标拾取、菜单、实例覆盖、撤销、滑条、多标签、网格更新、导出与小窗口；既有服务/三维/界面及便携包回归继续运行。结果与截图由交付报告列出。样例回归不能代替真实 200 MB 工程装配体、macOS 12 或另一台干净 Mac 的验收。

## 2026-10-03 Cocoa 表格无障碍兼容处理

实际无障碍客户端读取界面表格后，Qt 6.8.3 会将行数组持有的合成单元格提升至缓存，却未增加缓存自身的持有。随后表格刷新或菜单操作释放旧数组时可触发崩溃。Qt 官方在 [QTBUG-134784 对应提交](https://github.com/qt/qtbase/commit/b1ed5f656f064e553b33752f8e87d2f5b9553e38) 修复了该所有权关系。

`mac_accessibility.mm` 在应用层为固定 Qt 6.8.3 的已核验后端接口补足缓存持有，保留原生无障碍功能。它不改变零件选择、BOM 数据或外观历史，不替换 Qt 二进制；较新 Qt 的缓存接口和释放行为不与 6.8.3 混用。初始化核对版本和必要接口后安装处理，Windows 不编译该文件。

`stp_mac_accessibility_tests` 直接调用本进程的原生表格提供器，保留旧行/单元格数组直到表格销毁后再释放，检查提升仅增加一次缓存持有及重复查询不额外持有。已完成 100 轮表格创建、刷新和销毁，5,096 次提升及 5,096 次重复查询通过。测试还包含相同单元格 ID 的缓存替换检查；是否通过以最新 JSON 的 `sameCellIdReplacementBalanced` 为准。

运行 `build/stp_mac_accessibility_tests 输出报告.json` 得到正常报告。对照 `build/stp_mac_accessibility_tests 输出报告.json --no-fix` 在识别到缺失持有后写入失败 JSON，使用退出码 1 直接结束，避开已知无效的释放流程；这项预期失败不属于修复版回归失败。该专项只证明进程内所有权检查覆盖的范围，实际无障碍客户端、三维右键交互和最终便携包仍需分别验证，结果见交付报告。
